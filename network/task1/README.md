# Assignment 2, Task 1

## Running

1. Open a shell and run the server script with: `sudo python server.py`
1. Open another shell and run the client script with: `sudo python client.py`
1. In the client shell:
    1. Input a loopback IP address, such as `127.0.0.1` and press \<Enter>
    1. Input a message, and press \<Enter>
1. Observe the message in the server shell
